라벨 매니저 품목관리 미리보기/편집 기능 작업 지시서

1. 목적
* 품목관리에서 선택된 품목 1건의 데이터를 기준으로, 레거시 라벨 출력과 같은 규칙으로 공용라벨 시트를 치환한 미리보기를 제공한다.
* 품목관리의 행 선택, 주원료 및 함량 편집, 출력내용 미리보기는 공용라벨관리의 시트/플로팅 창 UX를 재사용하되 인스턴스와 상태는 품목관리 전용으로 분리한다.
* 구현 기준은 레거시 프로젝트 `.tmp\LabelManager`의 품목관리/라벨출력 흐름이다. 참고 화면은 `.tmp\레거시-품목관리.png`이다.

2. 레거시 기준 정리
* 품목관리 테이블의 동적 컬럼은 현재 라벨사이즈의 `BM_RICH_COLUMN` 목록이다. 현재 프로젝트에서는 `TColumn.datas`와 `TColumnContent.datas`가 이 역할을 한다.
* 컬럼 헤더의 표시명은 `RICH_COLUMN_NAME`, 치환 키워드는 `RICH_KEYWORD`이다. 라벨 원본에서는 `#`를 붙인 `#RICH_KEYWORD` 형태를 찾아 대체한다.
* 기본 항목은 별도 특별 키워드로 처리한다.
  - 품명: `#ITEMNAME` -> 선택 행의 `ItemOfMarket.item.itemName`
  - 주원료: `#ELEMENT` -> 선택 행의 주원료 RTF/텍스트. 품목관리 플로팅 창에서 편집 중이면 편집 중인 값을 우선 사용한다.
* 일반 동적 컬럼은 `BM_RICH_COL_CONTENT.RICH_COL_CONTENT_DATA` 값으로 대체한다. 현재 프로젝트에서는 `TColumnContent.get(columnId, itemId)?.dataString`이 해당 값이다.
* 바코드 컬럼은 저장된 문자열을 그대로 텍스트로 넣는 것이 아니라, 컬럼 타입/바코드 설정에 따라 바코드 객체의 payload로 적용한다. 레거시 기준은 `TYPE_BARCODE`, `TYPE_QR_CODE`, `TYPE_GS1_BARCODE` 계열 분기이다.
* 이미지 컬럼은 DB에 이미지 바이너리를 저장하지 않는다. 셀에는 확장자를 제외한 파일명 문자열만 저장된다.
  - 예: 셀 값 `비닐류PP`
  - 레거시 파일 위치: `C:\ITS\LabelManager\bmp files\비닐류PP.bmp`
  - 치환 키워드: 이미지 파일명이 아니라 이미지 타입 컬럼의 `#RICH_KEYWORD`이다. 예를 들어 컬럼 키워드가 `IMAGE`이면 `#IMAGE`를 이미지로 대체한다.
  - 현재 구현에서도 이미지 컬럼은 `TColumn.keyword`로 라벨 시트의 `#keyword` 위치를 찾고, 셀 값은 이미지 파일명 참조로만 사용한다.
* 레거시는 `CTableRowRTFMaker::ReplaceColumnInfoToCellValue`에서 `# + column.GetKeyword()`를 만들고, 컬럼 타입에 따라 텍스트/바코드/이미지 RTF로 대체한다. 현재 프로젝트의 구현도 이 구조를 LabelSheet workbook 조작 방식으로 옮기는 방향이 맞다.

3. 품목관리 테이블 동작
* 테이블 로딩 완료 후 첫 번째 데이터 행을 자동 선택한다.
* 선택 행이 바뀌면 품목관리 전용 플로팅 창의 두 탭 내용이 즉시 현재 행 기준으로 갱신된다.
* 품목관리 테이블 컬럼 구성은 현재 프로젝트의 `ItemManage` 기준을 유지한다.
  - 고정 컬럼: 발행, 라벨크기, 품명, 주원료
  - 동적 컬럼: `TColumn.datas` 순서의 공용라벨 사용 항목
  - 동적 셀 값: `TColumnContent.get(column.columnId, row.item.itemId)?.dataString ?? ''`

4. 플로팅 창 UX
* 품목관리 탭 진입 또는 품목 행 선택 시 품목관리 전용 플로팅 창을 자동으로 표시한다.
* 공용라벨관리의 미리보기 플로팅 창과 같은 창 컴포넌트/닫힘 애니메이션/탭 영역 미리보기 아이콘 UX를 사용한다.
* 단, 품목관리 플로팅 창은 공용라벨관리 플로팅 창과 별도 인스턴스여야 한다. 서로의 표시/닫힘/내용 상태가 섞이면 안 된다.
* 플로팅 창 닫기 클릭 시 공용라벨관리와 동일하게 탭 메뉴 라벨 영역에 미리보기 아이콘을 표시한다. 아이콘 클릭 시 품목관리 플로팅 창을 다시 표시하고 아이콘은 숨긴다.
* 플로팅 창 내부 상단 탭은 다음 2개다.
  - `주원료 및 함량`
  - `출력내용 미리보기`

5. `주원료 및 함량` 탭
* 공용라벨관리의 LabelSheet 기반 편집 경험을 사용하되 품목관리 전용 workbook/controller 인스턴스를 사용한다.
* 툴바는 최소 편집용으로 제한한다. 다음 기능은 제거한다.
  - 인쇄
  - 테두리
  - 셀 병합
  - 이미지 삽입
  - 바코드 삽입
* 시트는 A1 셀 하나만 사용한다.
* A1 셀 크기는 탭 ClientArea에 맞춰 자동 조정한다.
* 셀 선택의 파란색 하이라이트는 표시하지 않는다.
* A1 셀 클릭 시 선택 상태를 거치지 않고 바로 편집 상태로 진입한다.
* A1 값은 선택 행의 주원료 데이터에서 온다.
  - 기본값: `ItemOfMarket.item.element` / `ItemOfMarket.item.elementRTF`
  - 거래처/매장별 사용자 지정 주원료가 켜져 있으면 `ItemOfMarket.rtfText`를 우선 검토한다.
* 저장 포맷이 레거시 RTF이면 공용라벨관리에서 만든 RTF -> LabelSheet 변환 기능을 사용해 현재 LabelSheet 편집 데이터로 변환한다.
* 사용자가 A1 내용을 수정하면 품목관리 선택 행의 저장 관리 개체에 반영한다. 실제 DB 저장은 기존 품목관리 저장 흐름과 연결하되, 미리보기에는 저장 전 편집 중 값이 즉시 반영되어야 한다.

6. `출력내용 미리보기` 탭
* 현재 선택된 labelsize 개체의 저장된 공용라벨 시트 workbook을 기준으로 미리보기 전용 workbook을 만든다.
* 원본 labelsize workbook은 직접 수정하지 않는다. 선택 행이 바뀔 때마다 원본을 복제한 뒤 치환 결과를 적용한다.
* 치환 기준은 레거시 `CTableRowRTFMaker`와 동일하다.
  - `#ITEMNAME`: 선택 행 품명
  - `#ELEMENT`: `주원료 및 함량` 탭의 현재 편집값. RTF/리치 텍스트 서식이 있으면 가능한 한 유지한다.
  - `# + TColumn.keyword`: 해당 컬럼과 선택 품목의 `TColumnContent.dataString`
* 일반 텍스트/날짜 컬럼은 셀 텍스트로 대체한다.
* 바코드/QR/GS1 컬럼은 라벨 시트의 해당 키워드 위치 또는 해당 바코드 객체의 payload를 갱신한다. 단순 텍스트 치환으로 끝내지 않는다.
* 이미지 컬럼은 라벨 시트의 해당 키워드 위치를 이미지로 대체한다.
  - 키워드: `# + TColumn.keyword`
  - 파일명 값: `TColumnContent.dataString`
  - 레거시 호환 기본 검색 위치: `C:\ITS\LabelManager\bmp files\{파일명}.bmp`
  - 현재 앱 전용 이미지 저장소가 별도로 생기면, 먼저 현재 앱 저장소를 찾고 없으면 레거시 위치를 fallback으로 찾는다.
  - 파일이 없거나 파일명 값이 비어 있으면 레거시처럼 해당 이미지는 빈 값으로 처리하고, 필요하면 로그만 남긴다.
* 라벨 시트에 존재하지 않는 키워드는 무시한다. 필수 키워드 검증은 저장 시점의 공용라벨관리 규칙을 따른다.

7. 구현 우선순위
* 1단계: 선택 행 자동 선택 및 품목관리 전용 플로팅 창 표시/닫힘/아이콘 복귀 UX 구현.
* 2단계: `주원료 및 함량` 탭의 A1 단일 셀 편집기 구현 및 선택 행 주원료 값 로딩.
* 3단계: `#ITEMNAME`, `#ELEMENT`, 일반 동적 컬럼 텍스트 치환 미리보기 구현.
* 4단계: 바코드/QR/GS1 컬럼을 라벨 시트 바코드 객체 payload로 치환.
* 5단계: 이미지 컬럼을 `#keyword` 기준으로 찾아 파일명 참조 이미지를 삽입.
* 6단계: 저장 전 편집 중 주원료 값과 미리보기 동기화, 회귀 테스트 추가.

8. 주의사항
* 품목관리 이미지 값은 이미지 데이터가 아니라 파일명 참조다. DB BLOB나 HTTP 다운로드로 해석하지 않는다.
* 이미지 치환 키워드는 파일명이 아니라 컬럼 키워드다.
* 공용라벨관리의 원본 LabelSheet workbook을 직접 변경하지 말고 미리보기용 복사본에만 치환을 적용한다.
* 공용라벨관리 플로팅 창과 품목관리 플로팅 창 상태를 공유하지 않는다.
* 레거시와 비교할 때 기준 파일은 `.tmp\LabelManager\LabelManagerLib\TableRowRTFMaker.cpp`, `.tmp\LabelManager\LabelManagerLib\RichEditImageMaker.cpp`, `.tmp\LabelManager\LabelManager\LabelEditDlg.cpp`이다.
