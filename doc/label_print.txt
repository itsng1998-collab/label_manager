라벨 출력 탭을 다음과 같이 구현한다.
* 보완·예외 처리를 과도하게 하지 않는다.
* SQL Server 커밋 오류 전달·가능한 rollback까지만 수행한다.
* SQL Server DB 마이그레이션을 하지 않는다.
* 레거시의 라벨 출력 탭을 기준(동작등)으로 한다.
* 라벨 출력 UI를 더 보기 좋게 구현한다.
* 왼쪽의 테이블은 품목관리의 테이블위젯과 같은 위젯으로 구현한다.
* 오른쪽 출력(미리보기) 영역은 테이블의 선택 행을 기준으로 품목관리의 '출력내용 미리보기' 로직으로 프린터 출력 미리보기를 구현한다.
* '프린터 설정'은 공용라벨관리의 프린터 설정 다이얼로그를 그대로 가져와 사용하되 하단의 매수 영역을 추가 영역으로 변경하여 구현한다.
* '발행'은 선택된 프린터로 실물 프린트를 진행한다.
* 하단위 배치는 [프린터 설정] {선택된 프린터 라벨} [발행] 으로 배치한다.
* 명시하지 않은 내부 동작은 레거시를 기준으로 한다.
* 이미 미리보기 출력이 기본으로 배치되어 동작하고 있는거 같다 '미리보기' 버튼이 의미가 있는지 확인 후 의미가 없으면 미리보기 버튼은 배치하지 않는다. 
* 레거시 라벨 출력에서 검색 기능이 지원한다면 품목관리에서 사용한 검색영역을 보이게 하고 문자열 입력 후 검색을 선택하면 레거시와 같게 검색을 구현한다.
